# MDSave - Download Social Videos (Multi-Platform) v2.9.3

Ứng dụng tải video đa nền tảng không watermark với tốc độ cao, hỗ trợ tự động giải captcha và quét toàn bộ kênh video.

## Tính năng nổi bật
- **Tải video không watermark**: Hỗ trợ Douyin, TikTok và nhiều nền tảng mạng xã hội khác.
- **Quét kênh hàng loạt**: Nhập link kênh để tự động quét toàn bộ danh sách video và tải về hàng loạt.
- **Giải mã Captcha tự động**: Tích hợp giải thuật giả lập cử chỉ chuột và hệ thống nhận diện captcha dạng trượt.
- **Tải tốc độ cực đại**: Sử dụng công cụ `aria2c` đa luồng hoặc thư viện bảo mật `curl_cffi`.

## Hướng dẫn sử dụng
1. Chạy file `setup.bat` để thiết lập tự động môi trường Python và các thư viện cần thiết.
2. Khởi chạy ứng dụng:
   ```bash
   python main.py
   ```
